Renderizar MP4 1080×1920

O GitHub Pages e estatico: o MP4 e gerado no seu PC com Node + Playwright + FFmpeg. O site prepara o pacote do projeto.

  1. Clique em Baixar pacote (.b7zip).
  2. No PC, rode npm install e depois npm run render:frames -- pacote.b7zip.
  3. Rode npm run render:encode -- out/meu-video para gerar o MP4 e o relatorio de QA.
